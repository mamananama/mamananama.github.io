## Docker 이미지 다운받기

이미지는 컨테이너의 정의로, 애플리케이션을 실행하는데 필요한 모든 소프트웨어와 환경이 포함되어 있다.

아래와 같은 명령어를 통해 Docker 이미지를 다운받을 수 있으며, 다운받는 환경에서 Docker 컨테이너를 사용할 수 있게 된다.

```shell
docker image pull {docker_image_name}
```

해당 명령어를 통해 `docker_image_name` 이름으로 으로 구성된 이미지를 Docker가 찾아서 다운받게 된다.

## Docker 이미지 실행하기

이미지를 다운받은 후, 아래와 같은 명령어를 통해 Docker 이미지를 실행할 수 있다.

```shell
docker image run {docker_image_name}
```

## Docker 포트 매핑하기

하지만, 웹 서버를 실행하는 경우 예를들어, 8080 포트로 Tomcat을 실행할 때
해당 포트는 Docker 컨테이너 내부에서 실행되고 있기 때문에, 컨테이너 외부에서 이러한 포트가 나타나지 않으며 게시되지 않는 문제가 발생한다.

아래와 같은 명령어를 통하여 Docker를 실행하면, 컨테이너의 포트를 외부로 노출시킬 수 있다.

```shell
docker image run -p {external_port}:{internal_port} {docker_image_name}
```

예를들어, `docker image run -p 8080:8080 {docker_image_name}`와 같은 명령어를 실행하면, Docker 컨테이너에서 실행된 웹 어플리케이션을 `localhost:8080`으로 접근할 수 있다.

여기서 `{external_port}`는 컨테이너 외부에서 접근할 포트를 의미하며, `{internal_port}`는 컨테이너 내부에서 실행되는 포트를 의미한다.

이러한 포트 매핑 옵션을 통해 `{external_port}`를 브라우저에 입력하여 웹 어플리케이션으로 접근할 수 있게 된다.

만약, -p 옵션을 통해 포트를 연결하지 않으면, 컨테이너 내부에서 실행된 웹 어플리케이션은 외부에서 접근할 수 없다.

Docker toolbox를 사용할 경우 아래와 같은 명령어를 통하여 컨테이너가 실행중인 IP를 확인하여 웹 어플리케이션으로 접근할 수 있다.

```shell
docker-machine ip
```

## Docker 컨테이너 확인하기

현재 실행중인 Docker 컨테이너를 확인하려면, 아래와 같은 명령어로 확인할 수 있다.

```shell
docker container ls
```

## Docker 컨테이너 종료하기

실행중인 Docker 컨테이너를 종료하려면, 아래와 같은 명령어를 사용할 수 있다.

```shell
docker container stop {container_id}
```

여기서 `container_id`는 `docker container ls` 명령어를 통해 확인할 수 있다.

![docker container ls](/assets/posts/250615/docker_ls.png){:style="padding: 16px"}

container id 를 확인한 후, id 전체 혹은 앞부분의 일부만을 입력하여 종료할 수 있다.

예를 들어, 위의 이미지 기준, '`7b26`'만 입력하여도 컨테이너가 종료된다.

```shell
docker container stop 7b26
```
